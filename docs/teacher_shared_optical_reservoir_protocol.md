## 1. 最终方案结论

老师确认的方案与标准储备池计算范式一致：目标窗口和参考窗口分别进入两个**参数完全共享、内部参数固定**的光储备池分支，得到状态 `h_i` 与 `h_j`；训练阶段只求一个共享的线性输出层，不训练掩码、激光器参数、反馈参数、虚拟节点，也不增加可训练投影网络。

```text
目标窗口 x_i ──> 固定光储备池 R ──> h_i ──┐
                                               ├─> 同一输出权重 (b, w)
参考窗口 x_j ──> 固定光储备池 R ──> h_j ──┘
```

这里的“两个分支”表示对同一个**固定、共享、带记忆的状态更新规律**的两次取值，而不是两套参数不同的模型。老师原程序把窗口按时间顺序连续注入储备池，因此本实验的主实现也采用连续状态定义：先按时间顺序运行一次共享固定储备池并缓存每个月的状态，再按 `sample_id` 取出 `h_i` 和 `h_j` 组成孪生训练对。缓存状态只是在工程上避免重复仿真，不改变共享权重，也不会引入新的可训练参数。

本协议推荐的主模型为：

1. 固定共享光储备池按时间顺序连续编码；
2. 共享线性输出层；
3. 同时使用绝对 CPI 监督与成对 CPI 差值监督；
4. 用 Ridge/Tikhonov 闭式求解输出权重；
5. 通过历史参考值还原目标 CPI，并对多个参考预测进行聚合。

## 3. 固定共享光储备池

对按时间排序的窗口 `x_s`，固定光储备池给出 50 维状态：

```text
h_s = R(h_(s-1), x_s; theta_R),    h_s in R^50
```

其中 `theta_R` 包括 `SL_RC` 模型、12×50 固定掩码、输入增益、50 个虚拟节点、节点间隔、反馈延迟、激光器参数、噪声设置、状态截取规则和每段序列的初始状态。它们在训练、验证、测试及两个孪生分支之间完全一致，并且全部冻结。

这里的编码输入不只包含当前窗口 `x_s`，还包含由此前窗口决定的上下文状态 `h_(s-1)`。因此主实验必须固定窗口顺序、split 起点、初始条件和仿真方式；同一个 `sample_id` 始终对应同一个缓存状态。孪生模型随后读取两条状态记录：

```text
(sample_i_id, sample_j_id) -> (h_i, h_j)
```

这等价于两个参数共享的固定分支分别读取其已定义的时序上下文状态。所谓“共享”是共享 `theta_R` 和状态更新规律，不要求目标分支与参考分支在取值时具有相同的瞬时内部状态。

状态标准化参数也只由 50 个训练状态计算：

```text
mu_h, sigma_h = statistics({h_s | s in train50})
z_s = (h_s - mu_h) / sigma_h
```

标准化不是新的可训练网络，只是训练集拟合的数据变换。若某一维方差为零，应按实现约定将其缩放量置为 1，避免除零。

## 4. 只训练一个共享输出层

共享输出函数定义为：

```text
f(h_s) = b + w^T z_s
```

模型唯一需要学习的量是偏置 `b` 和 50 维输出权重 `w`。偏置不参与 Ridge 惩罚，储备池内部参数不更新。

### 4.1 绝对值目标

普通单光储备池直接用 50 个训练目标拟合：

```text
L_abs = (1 / 50) * sum_s [b + w^T z_s - y_s]^2
```

这一项给输出函数提供 CPI 的绝对水平锚点，并覆盖全部 50 个训练月份。

### 4.2 孪生差值目标

对于合法训练对 `(i, j)`，两个分支共享同一个 `f`，因此：

```text
f(h_i) - f(h_j) = w^T (z_i - z_j)
delta_y_ij = y_i - y_j

L_pair = sum_(i,j) q_ij * [w^T (z_i - z_j) - delta_y_ij]^2
```

偏置 `b` 在差值中自动抵消。`q_ij` 使用“目标月份平衡”权重：同一个目标 `i` 下所有参考对的权重和相同，避免较晚目标因可选参考更多而支配损失。若目标 `i` 有 `n_i` 个参考且共有 38 个可作为 `i` 的训练目标，可取：

```text
q_ij = 1 / (38 * n_i)
```

差值目标单独使用时不能确定绝对偏置，因此必须通过已知参考值 `y_j` 还原预测，或与绝对值目标联合使用。

### 4.3 推荐的联合目标

```text
L_joint = L_abs + lambda_pair * L_pair + alpha * ||w||_2^2
```

- `alpha`：输出权重的 Ridge/Tikhonov 正则强度；
- `lambda_pair`：孪生差值监督相对绝对监督的权重；
- `lambda_pair = 0`：退化为普通单光储备池线性读出，可作为同状态下的直接基线；
- `lambda_pair > 0`：在不增加储备池参数的前提下，让同一输出权重同时满足绝对值和相对变化关系。

该问题仍是线性最小二乘问题。可将绝对行写为 `[1, z_s^T]`，差值行写为 `[0, (z_i-z_j)^T]`，按损失权重缩放后堆叠，再一次性用 Ridge/Tikhonov 闭式求解 `(b, w)`。不需要反向传播、Adam 或神经网络训练。

## 5. 741 个训练对的正确解释

训练对使用不重叠的 12 个月窗口。当前定义中，`gap=1` 表示参考窗口结束月份与目标窗口开始月份至少相隔 1 个月。对连续的 50 个训练目标，合法有向组合为：

```text
1 + 2 + ... + 38 = 741 对
```

这 741 行不是 741 个独立训练样本，也没有引入 741 个月数据：

- 它们只由原来的 50 个窗口和 50 个标签重复组合得到；
- 同一个 `h_s` 和 `y_s` 会出现在许多训练对中；
- 可作为目标端 `i` 的月份有 38 个，但 50 个训练月份的并集均参与绝对监督或参考端；
- 实验的原始样本量、标准化拟合样本量和可访问信息量仍然是 50 个月；
- MAE、RMSE 必须按唯一目标月份计算，不能把同一目标的多个参考对当作多个独立测试样本。

因此报告中应写“由 50 个训练月份构造 741 个关系约束”，不能写“训练集扩充为 741 个独立样本”。

## 6. 推理与多参考聚合

给定目标窗口 `i` 和训练参考窗口 `j`，孪生分支的单参考预测为：

```text
y_hat_i^(j) = y_j + w^T (z_i - z_j)
```

对每个验证或测试目标，从固定训练 50 窗口中按输入信息选出 `K` 个参考，再聚合：

```text
y_hat_i = mean_j(y_hat_i^(j))
```

也可在验证阶段比较按输入窗口距离倒数加权的聚合。候选 `K`、聚合方式、`alpha` 和 `lambda_pair` 均只能用验证集选择。主评价是目标级 RMSE，MAE 为辅助指标；若并列，优先更简单的配置。

直接预测 `f(h_i)` 可作为联合读出的诊断输出；孪生主输出应采用参考还原式，以体现差值关系的作用。报告必须明确使用了哪一种输出，不能混用后只报告较优结果。

## 7. 为什么本方案不使用可训练投影网络

此前“共享可训练投影网络 + 孪生回归”会在 `h` 与输出层之间再加入可学习矩阵、激活函数或多层网络。该结构虽然也能保持双支权重共享，但不符合本次老师给出的约束：**储备池只训练输出权重，其他部分参考文献并固定**。

在本实验只有 50 个原始训练月份时，可训练投影还会带来额外问题：

- 参数量相对样本量过大，容易拟合验证区间而不能迁移到测试区间；
- 优化结果同时混合“表示学习”和“孪生差值”的影响，不利于解释孪生结构是否有效；
- 无法与只训练线性读出的单光储备池做干净的单因素比较。

因此本轮不训练投影层。需要改善表示时，优先引用文献确定固定储备池参数，或将其作为下一轮独立实验；不能在当前正式对比中暗中增加可训练层。

## 8. 连续状态是本轮主实现

主流程 `prepare_cpi_inputs.m -> run_cpi_simulation.m -> extract_cpi_states.m` 会把一个 split 内的所有 50 节点窗口按月份顺序首尾相接，作为一条长序列仿真一次，再每连续 50 个响应点切出一个月的状态。

这与老师原始程序的串行注入方式一致。由于光储备池具有延迟反馈记忆，后一个窗口的状态本来就应由当前输入和此前储备池状态共同决定：

```text
h_s = R(h_(s-1), x_s; theta_R)
```

因此，本轮不再把连续记忆视为错误或“代理”。只要以下上下文契约固定，缓存状态就是共享固定编码器的正式输出：

- 每个 split 内按 `target_date` 严格升序注入，禁止重新排序；
- train、val、test 各自从已声明且可复现的模型初始条件开始；
- 三个 split 使用同一模型、掩码、缩放、输入增益、反馈参数、噪声设置和状态截取方式；
- `sample_id`、月份与状态行一一对应，不能按当前文件行号重新编号；
- 单光与孪生模型必须读取完全相同的缓存状态。

在孪生阶段，并不需要为 741 个训练对重复运行 1482 次光储备池。对每个唯一月份只缓存一次 `h_s`，之后：

```text
pair(sample_i_id, sample_j_id) -> lookup(h_i, h_j)
```

这种“先连续编码、后按 ID 配对”与两个分支共享同一固定状态更新规律相符。训练的仍然只是输出层 `(b,w)`；缓存和索引不会把孪生网络降格为普通数据预处理，也不会增加模型参数。

需要在报告中明确写出：这里的分支输入语义是“当前 12 个月窗口 + 已定义的历史储备池上下文”，而不是“从零状态独立处理一个窗口”。如果未来改为独立窗口语义，应作为另一项消融，不得与本主实验混称。

### 9.2 当前独立窗口脚本不能作为正式结果

本轮曾起草 `run_mom_recent50_independent.m`、`run_independent_window_states.m` 作为独立复位方向的实验接口，但静态审查后已从正式改动中移除，避免被误运行。审查发现：

```text
单窗口驱动长度 = 50 × 40 ps = 2.00 ns
反馈延迟       = 2.04 ns ≈ 51 个节点间隔
```

脚本每次只驱动 50 个节点，尚未让当前窗口完整经过一次反馈回路，就截取 50 维状态。这样的状态不能充分体现延迟储备池动力学，因此不能宣称“每窗口独立状态”已经正式可用，也不应让杜艾佳现在直接运行 train+val 的 95 次仿真。

如要把独立复位作为后续消融，必须先修改并验证协议：

1. 每个窗口从同一确定初始条件开始；
2. 将同一 masked window 重复驱动或增加明确的 washout，使总驱动时间至少覆盖 2 个反馈周期；
3. 当前窗口周期为 2.00 ns、反馈周期为 2.04 ns，因此若按完整 50 节点窗口重复，至少需要 `ceil(2×2.04/2.00)=3` 轮，再从后段截取状态；
4. 比较 2、3、4 个及更多反馈周期后的状态差，验证状态是否收敛，并在训练/验证集上固定周期数；
5. train、val 通过收敛与复现检查后才能生成独立测试状态；
6. 独立复位结果单列为消融，单光和孪生都必须使用同一批独立状态。

独立窗口消融的测试状态仍需遵守“验证冻结后才加载”的规则。看到测试指标后不得继续调整反馈周期、截取位置、`alpha`、`lambda_pair`、`K`、参考选择或聚合方式。

## 10. 公平对比要求

正式“单光储备池 vs 孪生光储备池”对比必须满足：

| 比较项 | 单光储备池 | 孪生光储备池 |
| --- | --- | --- |
| 原始 CPI 窗口 | 同一份 12 个月环比窗口 | 完全相同 |
| 时间划分 | 50/45/47 | 完全相同 |
| 可访问训练月份 | 50 | 50；741 对只是内部关系约束 |
| 光储备池模型、掩码、物理参数 | 固定 | 完全共享、固定 |
| 状态生成方式 | 同一串行注入、连续状态 | 读取同一批连续缓存状态 |
| 状态标准化 | 只拟合训练 50 | 复用同一训练标准化 |
| 可训练参数 | 线性输出 `(b,w)` | 同样只有共享线性输出 `(b,w)` |
| 监督目标 | `L_abs` | `L_abs + lambda_pair L_pair` |
| 验证用途 | 选 `alpha` | 选 `alpha/lambda_pair/K/聚合` |
| 最终指标 | 47 个唯一测试目标的 MAE/RMSE | 同样按 47 个唯一目标计算 |

为判断增益来自哪里，至少报告以下消融：

1. 普通读出：`lambda_pair=0`，输出 `f(h_i)`；
2. 纯差值读出：只用 `L_pair`，以 `y_j` 还原并聚合；
3. 联合读出：`L_abs + lambda_pair L_pair`，以参考还原并聚合；
4. 联合模型的直接输出 `f(h_i)`，仅作诊断。

所有表格同时报告 MAE、RMSE、目标月份数量、训练原始月份数量、训练关系对数量和状态模式。本轮只有遵守既定串行上下文契约、且单光与孪生共用同一批连续状态的结果，才能标为“正式老师方案结果”；独立复位结果必须单列为消融。

- [ ] 两条分支使用同一个固定 `SL_RC`、同一掩码和同一物理参数；
- [ ] 每个 split 严格按时间顺序连续注入，并记录初始条件和上下文契约；
- [ ] 只训练偏置和线性输出权重，没有可训练投影层；
- [ ] 741 对明确记录为 50 个月内部关系，不作为独立样本数；
- [ ] 验证/测试参考选择未使用 `y_i`、`delta_y` 或预测误差；
- [ ] 验证选择期间没有打开测试状态或测试标签；
- [ ] 冻结配置后才读取 `states_test.mat`；
- [ ] 单光与孪生对比使用同一批连续缓存状态，并按唯一目标计算指标；
- [ ] 独立复位草稿未被误当作正式结果；如重新实现消融，驱动至少覆盖两个反馈周期并验证状态收敛。

## 12. 方法依据

- [Appeltant et al., *Information processing using a single dynamical node as complex system*, Nature Communications, 2011](https://www.nature.com/articles/ncomms1476)：单非线性节点、延迟反馈、时间复用虚拟节点、固定输入掩码和线性读出的基础架构。
- [Paquot et al., *Optoelectronic Reservoir Computing*, Scientific Reports, 2012](https://www.nature.com/articles/srep00287)：光电延迟储备池、虚拟节点及线性读出的实验实现。
- [Brunner et al., *Parallel photonic information processing at gigabyte per second data rates using transient states*, Nature Communications, 2013](https://www.nature.com/articles/ncomms2368)：半导体激光储备池的瞬态状态与 Tikhonov 线性读出训练。
- [Lukoševičius, *A Practical Guide to Applying Echo State Networks*, 2012](https://link.springer.com/chapter/10.1007/978-3-642-35289-8_36)：固定储备池、线性读出，以及处理多条独立短序列时初始状态与 washout 的工程原则。
- [Bromley et al., *Signature Verification using a “Siamese” Time Delay Neural Network*, NeurIPS, 1993](https://proceedings.neurips.cc/paper/1993/hash/288cc0ff022877bd3df94bc9360b9c5d-Abstract.html)：孪生结构中两个输入分支共享参数的经典定义。本文献支持“共享分支”概念；本项目的 CPI 差值回归损失是针对当前任务设计的，不应误称为该论文原有损失。

以上文献共同支持“固定动力学储备池 + 只训练线性输出层”和“孪生双支参数共享”两个设计原则；联合绝对/差值目标、目标平衡权重与多参考聚合属于本项目面向小样本 CPI 回归的具体实现，需要通过上述验证—冻结—测试流程实证评价。
