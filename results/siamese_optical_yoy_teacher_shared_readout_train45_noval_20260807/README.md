# 同比孪生光储备池 train45/test47 结果

数据使用 `cpi_data_lastyear=100.csv` 的 `actual` 同比序列，以连续前12个月预测下1个月。训练目标为2018-09至2022-05（45个），无验证集；测试目标为2022-06至2026-04（47个）。

本次使用 MATLAB 新上传的单路连续窗口状态缓存，并在 Python 中构造目标/参考语义分支、共享一个线性输出权重，预测目标与参考的CPI差值。该结果不是两个分支在 MATLAB 中同时仿真的严格显式 Twin 结果。

- 单光储备池：MAE=0.629775，RMSE=0.709513
- 孪生共享读出：MAE=1.227090，RMSE=1.512413
- 相对单光储备池：MAE变化=94.85%，RMSE变化=113.16%（正数表示误差增大）

配置在读取本次同比测试指标前固定为：gap=1、K=5、均值聚合、alpha=100、pair_weight=0.1。测试参考只来自train45，选择过程不使用测试标签。
