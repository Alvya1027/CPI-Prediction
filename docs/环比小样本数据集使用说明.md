# 环比小样本数据集使用说明

供双网络/孪生光储备池实验使用。请与单网络环比实验保持相同的数据口径和日期划分。

## 1. 数据来源

- 原始文件：`data_processed/cpi_data_lastmonth=100.csv`
- 目标列：`actual`，含义为 CPI 环比指数（上月=100）
- 不使用：`cpi_data_lastyear=100.csv`（同比）、`cpi_month_ratio.csv`（派生比值）
- 本实验不把环比预测转换为同比；指标直接在环比尺度上计算。

## 2. 输入窗口

对每个目标月份，使用 `actual` 序列中连续的前 12 个月作为输入，预测下一个月：

```text
X(t) = [actual(t-12), ..., actual(t-1)]
y(t) = actual(t)
```

例如：2014-07 的输入为 2013-07—2014-06，目标为 2014-07。

已生成的统一窗口文件：

`matlab/optical_reservoir_cpi_mom_recent50_20260730/data/cpi_windows.mat`

对应索引和日期文件：

`matlab/optical_reservoir_cpi_mom_recent50_20260730/data/sample_index.csv`

## 3. 数据划分

| 数据集 | 目标月份 | 数量 |
|---|---|---:|
| 训练集 | 2014-07—2018-08 | 50 |
| 验证集 | 2018-09—2022-05 | 45 |
| 测试集 | 2022-06—2026-04 | 47 |

训练集用于拟合读出层、标准化参数和模型专属参数；验证集用于选参数；测试集只用于最终评价。标准化参数只能由训练集拟合，验证集和测试集直接复用。

## 4. 双储备池实验注意事项

1. 双网络与单网络必须使用同一份 12 个月环比窗口、同一 `sample_index.csv` 和同一 50/45/47 划分。
2. 保留 `sample_id` 与 `target_date`，不要按文件当前行号重新对应日期。
3. 验证集和测试集的参考窗口、配对样本不能使用真实目标值筛选，避免信息泄漏。
4. 双储备池的状态文件和结果请另存到独立目录，不覆盖 `optical_reservoir_mom_recent50_20260730`。
5. 如果另做同比实验，应单独标注“同比”，不能与本环比结果混在同一指标表中。
