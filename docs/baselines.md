# 基线模型 (Baselines) 文档

本文档详细描述了 CPI（居民消费价格指数）预测项目中使用的基线模型、相空间重构方法、数据处理流程以及模型的评估结果。

---

## 1. 概述

本项目旨在利用**相空间重构**技术结合多种机器学习算法，对中国 CPI（居民消费价格指数）环比数据进行短期预测。整体流程遵循"数据预处理 → 特征构建 → 模型训练 → 性能评估"的标准机器学习范式，各阶段紧密衔接，形成完整的预测流水线。

## 3. 相空间重构 (Phase Space Reconstruction)

### 3.1 基本原理

相空间重构是混沌理论中的核心方法，其理论基础来源于 **Takens 嵌入定理**（1981年）。Takens 证明：对于一个一维动力系统的时间序列 $\{x(t)\}$，只要选取合适的嵌入维数 $m$ 和延迟时间 $\tau$，就可以通过构造 $m$ 维延迟坐标向量：

$$\mathbf{X}(t) = [x(t), x(t-\tau), x(t-2\tau), \ldots, x(t-(m-1)\tau)]$$

在**微分同胚**的意义下等价于原系统的吸引子。这意味着重构后的相空间向量能够完整保留原系统的动力学信息，为后续的预测建模提供高质量的特征表示。

**图示说明：**
- 原始序列 $x(t)$ 的每个点被扩展为一个 $m$ 维的相空间向量
- 向量的各分量之间保持着系统的动力学关联
- 重构后的数据集可直接用于监督学习框架（$m$ 个特征 → 1 个目标）

### 3.2 参数选取

本项目通过以下两种经典方法分别确定延迟时间 $\tau$ 与嵌入维数 $m$，最终选定的参数为：

> **延迟时间 $\tau = 2$，嵌入维数 $m = 10$**

#### 3.2.1 延迟时间 τ —— 互信息法 (Mutual Information)

互信息法由 Fraser 和 Swinney 于 1986 年提出，用于衡量两个变量之间的统计依赖程度。对于时间序列 $x(t)$，计算 $x(t)$ 与 $x(t+\tau)$ 之间的互信息量 $I(\tau)$：

**核心思想：**
- 随着延迟 $\tau$ 的增大，$x(t)$ 与 $x(t+\tau)$ 的相关性逐渐减弱
- 当互信息 $I(\tau)$ 下降到**第一个极小值**时，说明此时两个分量之间已基本独立
- 选取该点作为最优 $\tau$，使嵌入向量各分量既保留系统动力学信息又不过度冗余

**数学公式：**
$$I(X;Y) = \sum_{x,y} P(x,y) \log\left(\frac{P(x,y)}{P(x)P(y)}\right)$$

其中 $P(x,y)$ 为联合概率分布，$P(x)$ 和 $P(y)$ 为边缘概率分布，通过二维直方图估计得到。

#### 3.2.2 嵌入维数 m —— Cao 方法

Cao 方法（1997年）是对传统虚假最近邻法（FNN）的改进，无需人为设定阈值即可自动确定嵌入维数。

**核心思想：**
- 对于候选维度 $d$，对每个相空间点 $\mathbf{X}_i$ 找到其在 $d$ 维空间中的最近邻 $\mathbf{X}_{NN(i)}$
- 计算从 $d$ 维扩展到 $d+1$ 维后，两点距离的缩放比：
  $$a(i) = \frac{\|\mathbf{X}_i^{(d+1)} - \mathbf{X}_{NN(i)}^{(d+1)}\|}{\|\mathbf{X}_i^{(d)} - \mathbf{X}_{NN(i)}^{(d)}\|}$$
- 对所有点取平均得到 $E_1(d) = \frac{1}{N_d} \sum_{i=1}^{N_d} a(i)$
- 当 $E_1(d)$ 随 $d$ 增大趋于**稳定**时，表明进一步增加维度已不能有效重构系统，此时的 $d$ 即为最优嵌入维数 $m$。

### 3.3 重构结果

基于确定的参数 $\tau=2, m=10$，对 CPI 环比数据进行相空间重构，生成用于建模的特征数据集。

**重构后的数据集结构 (`cpi_data_lastmonth=100.csv`)：**
- **年份 (`year`)** 和 **月份 (`month`)**：时间标识
- **相空间特征 (`month-19`, `month-17`, ..., `month-1`)**：共 10 列，对应 $\mathbf{X}(t) = [x(t), x(t-2), x(t-4), \ldots, x(t-18)]$ 的 10 个延迟坐标分量
- **目标值 (`actual`)**：当期的 CPI 环比指数（上月=100）

## 4. 基线模型 (Baseline Models)

**代码文件：** `src/baselines_small.py`

本项目共实现了六种基线预测模型，涵盖了从简单统计方法到复杂机器学习算法的多层次对比。

### 4.1 模型列表

| 模型类型 | 模型名称 | 描述 |
| :--- | :--- | :--- |
| 统计基线 | **Naive** (朴素预测) | 预测值直接等于上一时刻的实际值。作为评估其他模型性能的基准参考。 |
| 线性模型 | **Ridge** (岭回归) | L2 正则化线性回归，通过惩罚大的权重系数来防止过拟合。 |
| 集成学习 | **RandomForest** (随机森林) | 基于多棵决策树的集成方法，采用平均策略进行预测，具有良好的抗过拟合能力。 |
| 核方法 | **SVR** (支持向量回归) | 使用 RBF（高斯径向基）核函数，在高维特征空间中寻找最优超平面进行回归预测。 |
| 梯度提升 | **XGBoost** | 高效的梯度提升树算法，基于决策树的加法模型，具有出色的预测精度和效率。 |
| 时间序列模型 | **SARIMAX** (带外生变量的季节性自回归移动平均) | 经典的时间序列分析模型，本项目中采用均值模型作为基准。 |

### 4.2 模型超参数

为了确保对比的公平性，所有模型的超参数均经过系统性搜索（网格搜索/随机搜索）进行优化。

| 模型名称 | 关键超参数 |
| :--- | :--- |
| **Ridge** | `alpha=15.9777` |
| **RandomForest** | `n_estimators=195`, `max_depth=6`, `max_features=0.1201` |
| **SVR** | `kernel='rbf'`, `C=19.0967`, `epsilon=0.05413`, `gamma=0.0003569` |
| **XGBoost** | `max_depth=7`, `n_estimators=227`, `learning_rate=0.0472`, `colsample_bytree=0.329`, `subsample=0.373` |
| **SARIMAX** | `order=(0, 0, 0)` |

### 4.3 数据处理流程

1. **数据加载**：读取经过相空间重构的 CPI 环比数据（上月=100）。
2. **特征工程**：对月份特征进行独热编码（One-Hot Encoding），将分类变量转换为数值特征。
3. **数据划分**：按时间顺序将数据划分为**训练集 (Train)**、**验证集 (Validation)** 和**测试集 (Test)**，避免数据泄露。
4. **标准化**：对特征数据进行标准化处理 (Z-Score Normalization)，使其均值为 0、方差为 1，有助于加快模型收敛并消除特征间的量纲差异。
5. **同比换算**：模型在环比数据上训练，但最终需要预测同比数据（上年同月=100）。代码中实现了换算逻辑：
   $$\text{预测同比}_t = \text{实际同比}_{t-1} \times \frac{\text{预测环比}_t}{\text{去年同月实际环比}_{t-12}}$$

## 5. 评估指标

为全面评估各模型的预测性能，本项目采用以下四种常用的时间序列预测评估指标：

### 5.1 MAE (平均绝对误差, Mean Absolute Error)

$$\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

**含义：** 预测值与真实值之间的平均绝对偏差。衡量模型预测值的平均偏差幅度，值越小越好。

### 5.2 RMSE (均方根误差, Root Mean Squared Error)

$$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}$$

**含义：** 对误差进行平方后取平均再开方。与 MAE 相比，RMSE 对**较大的误差**（预测离群点）更加敏感，适合用于评估模型在极端情况下的表现。

### 5.3 MAPE (平均绝对百分比误差, Mean Absolute Percentage Error)

$$\text{MAPE} = \frac{1}{n} \sum_{i=1}^{n} \left| \frac{y_i - \hat{y}_i}{y_i} \right| \times 100\%$$

**含义：** 以百分比形式衡量预测误差，直观反映了预测值相对于真实值的偏差比例，便于跨量纲比较。

### 5.4 MASE (平均绝对缩放误差, Mean Absolute Scaled Error)

$$\text{MASE} = \frac{\text{MAE}}{\text{MAE}_{\text{Naive}}}$$

**含义：** 以 Naive 模型（预测值=上一期实际值）的 MAE 为基准进行缩放的误差指标。
- **MASE < 1**：表示该模型的预测性能优于朴素预测基线。
- **MASE > 1**：表示该模型的预测性能劣于朴素预测基线。

## 6. 实验结果

**结果文件：** `results/tables/baseline_results.csv`（指标）, `results/tables/baseline_predictions.csv`（具体预测值）

### 6.1 测试集预测指标对比

下表展示了各基线模型在测试集上的预测性能对比：

| 模型 (Model) | MAE | RMSE | MAPE | MASE |
| :--- | :---: | :---: | :---: | :---: |
| **Naive** | 0.3553 | 0.4796 | 0.353% | **1.0000** |
| **Ridge** | 0.2897 | 0.3837 | 0.288% | 0.8153 |
| **RandomForest** | 0.2813 | 0.3493 | 0.280% | 0.7917 |
| **SVR** | 0.3013 | 0.3760 | 0.300% | 0.8480 |
| **XGBoost** | **0.2618** | **0.3384** | **0.260%** | **0.7368** |
| **SARIMAX** | 0.3156 | 0.4016 | 0.314% | 0.8882 |

### 6.2 结果分析

1. **最佳模型：XGBoost**
   XGBoost 模型在所有评估指标上均表现最优，其 MAE (0.2618) 相比 Naive 基线提升了 **26.3%**，MASE 值为 0.7368，表明其预测误差仅为朴素预测模型的 73.7%。这验证了基于树的梯度提升方法在捕捉 CPI 数据的非线性模式和复杂季节性特征方面的强大能力。

2. **集成与非线性模型优于线性模型**
   RandomForest (MASE: 0.7917) 和 XGBoost 均优于线性的 Ridge 回归 (MASE: 0.8153)，这表明 CPI 数据中存在着线性模型无法捕捉的非线性关系。

3. **所有模型均优于 Naive 基线**
   所有模型的 MASE 均小于 1，验证了特征工程（相空间重构）和机器学习算法的有效性。

4. **SVR 表现略逊**
   SVR (MASE: 0.8480) 虽然优于 Naive 基线，但不及其他复杂模型。这可能与 RBF 核参数的敏感性以及数据的复杂特征有关。

5. **SARIMAX 作为经典统计方法的对照**
   SARIMAX (MASE: 0.8882) 表现最接近 Naive 基线，这可能是因为本项目中采用了 $(0,0,0)$ 阶的均值模型作为对照，而非完全利用其自回归特性。
