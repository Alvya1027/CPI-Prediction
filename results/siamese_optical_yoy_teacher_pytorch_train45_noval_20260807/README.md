# 老师结构 PyTorch 孪生光储备池：同比 train45/test47

本实验真正采用老师示例中的共享 `Linear-ReLU-BatchNorm` 骨干网络：50维 MATLAB 光储备池状态经过共享骨干得到32维嵌入，嵌入差值进入非线性回归头预测 CPI 同比差值，再加回训练参考月份的已知 CPI。

- 训练目标：2018-09至2022-05，共45个；无验证集
- 测试目标：2022-06至2026-04，共47个
- 训练配对：561条，仅由train45内部派生
- 测试参考：每个目标5个，全部来自train45，选择不使用测试标签
- 固定随机种子：42, 52, 62；最终结果为三个种子的预测平均，不挑选最好种子

## 测试结果

- 单光储备池：MAE=0.629775，RMSE=0.709513
- 老师结构 PyTorch 孪生（三种子平均）：MAE=0.665011，RMSE=0.791659
- 相对单光储备池：MAE变化=5.60%，RMSE变化=11.58%（负数为改善，正数为退化）

该实验使用的是单路连续窗口 MATLAB 状态缓存，目标/参考分支在 PyTorch 中共享非线性骨干；不是 MATLAB 内同时仿真的显式双分支 Twin。
