# 老师结构 PyTorch 孪生光储备池：环比 train45/test47

本实验使用审计通过的 MATLAB 显式 Twin 唯一窗口状态缓存。50维光储备池状态经过共享 `Linear-ReLU-BatchNorm` 骨干得到32维嵌入，嵌入差值进入非线性回归头预测 CPI 环比差值，再加回训练参考月份的已知 CPI。

- 训练目标：2018-09至2022-05，共45个；无验证集
- 测试目标：2022-06至2026-04，共47个
- 训练配对：561条，仅由train45内部派生
- 测试参考：每个目标5个，全部来自train45，选择不使用测试标签
- 固定随机种子：42, 52, 62；正式结果为三种子预测平均

## 测试结果

- 单光储备池同状态基准：MAE=0.306424，RMSE=0.412914
- 老师结构 PyTorch 孪生（三种子平均）：MAE=0.329296，RMSE=0.447925
- 相对单光储备池：MAE变化=7.46%，RMSE变化=8.48%（负数为改善，正数为退化）

网络结构、训练轮数和随机种子均从同比实验原样迁移，没有根据环比测试结果调整。
